Google Play Store Build Guide

Version 14

Complete guide for packaging and publishing your IBN app to the Google Play Store

Important: Publishing to the Play Store is a manual process. This guide walks you through packaging your web app as a Trusted Web Activity (TWA) and submitting it to Google Play Console.

Required Input URLs

You will need these URLs during the packaging process:

  • Manifest URL: {origin}/manifest.webmanifest
  • Digital Asset Links URL: {origin}/.well-known/assetlinks.json
  • Privacy Policy URL: {origin}/#privacy-policy

Prerequisites

1. Google Play Console Account

Sign up at play.google.com/console (one-time $25 registration fee)

2. Required Visual Assets

All assets are already prepared in your repository:

  • App icons (192x192 and 512x512): frontend/public/assets/generated/ibn-app-icon.dim_192x192.png and ibn-app-icon.dim_512x512.png
  • Feature graphic (1024x500): frontend/public/assets/generated/ibn-feature-graphic.dim_1024x500.png
  • Screenshots (1080x1920): frontend/public/assets/generated/playstore-screenshot-1.dim_1080x1920.png and playstore-screenshot-2.dim_1080x1920.png

3. Privacy Policy

Available at: {origin}/#privacy-policy

Packaging Options

Choose one of these tools to package your web app as a TWA:

Option A: Bubblewrap (Recommended for developers)

Google's official CLI tool. Requires Node.js and Android SDK.

Quick start using the helper script for Version 14:

cd frontend/scripts/twa
./bubblewrap-release.sh

The script is located at: frontend/scripts/twa/bubblewrap-release.sh

It will prompt you for:

  • Your deployed app URL (origin)
  • Android package name (e.g., com.yourcompany.ibn)

The script will automatically:

  • Initialize the Bubblewrap project
  • Generate or reuse a signing key
  • Build the AAB and APK files
  • Extract the SHA-256 fingerprint
  • Print the full paths to generated artifacts
  • Provide clear next steps for Digital Asset Links configuration

Option B: PWABuilder (Easiest for beginners)

Web-based tool with visual interface:

  1. Visit pwabuilder.com
  2. Enter your manifest URL: {origin}/manifest.webmanifest
  3. Click "Package for Stores" and select "Android"
  4. Download the generated AAB or APK file

Digital Asset Links Configuration

Critical Step: You must update the Digital Asset Links file with your actual Android package name and SHA-256 certificate fingerprint.

File Location

frontend/public/.well-known/assetlinks.json

Two Placeholders to Replace

  1. REPLACE_WITH_YOUR_PACKAGE_NAME - Your Android package name (e.g., com.yourcompany.ibn)
  2. REPLACE_WITH_YOUR_SHA256_FINGERPRINT - The SHA-256 fingerprint from your signing key

Extracting SHA-256 Fingerprint

If you used the Bubblewrap helper script, it will print the fingerprint for you. Otherwise, extract it manually:

keytool -list -v -keystore your-keystore.keystore -alias your-key-alias

Look for the "SHA256:" line in the output (format: XX:XX:XX:...).

After Updating

Redeploy your frontend so the updated file is accessible at: {origin}/.well-known/assetlinks.json

Verify deployment using Google's tester: Digital Asset Links Tester

Upload to Google Play Console

  1. Go to Google Play Console
  2. Create a new app or select an existing one
  3. Navigate to "Release" → "Production" → "Create new release"
  4. Upload your AAB file (Android App Bundle)
  5. Complete the store listing with:
    • App description and screenshots
    • Feature graphic from: frontend/public/assets/generated/ibn-feature-graphic.dim_1024x500.png
    • Privacy Policy URL: {origin}/#privacy-policy
  6. Submit for review

Troubleshooting

Common Issues

  • Digital Asset Links verification failed: Ensure assetlinks.json is accessible at the deployed URL and contains the correct package name and fingerprint
  • App not opening correctly: Verify your manifest URL is accessible and contains valid JSON
  • Build errors: Check that you have the required Android SDK and build tools installed
